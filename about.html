About Us

SocialApp adalah simulasi platform media sosial sederhana yang dikembangkan untuk Project UTS mata kuliah Front-End Programming Fakultas Teknologi Informasi Universitas Tarumanagara.

Tentang Project

Website ini dirancang untuk menerapkan konsep pengembangan web front-end menggunakan HTML, CSS, JavaScript, dan jQuery tanpa menggunakan backend maupun database. Seluruh interaksi dan data disimulasikan di sisi client menggunakan Local Storage dan manipulasi DOM.
